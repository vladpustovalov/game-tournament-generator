# Game Tournament Generator

Веб-приложение для создания и управления турнирами по различным играм. Позволяет автоматически формировать турнирные сетки (brackets), добавлять участников, фиксировать результаты матчей и просматривать статистику.

## Статус проекта

Проект находится на этапе проектирования. Разработка основных компонентов приложения планируется в рамках MVP.

## Основные возможности MVP

- Создание и настройка игровых турниров.
- Добавление и управление участниками.
- Автоматическая генерация турнирной сетки.
- Отображение матчей и текущего этапа турнира.
- Ввод и сохранение результатов матчей.
- Автоматическое продвижение победителей в следующий раунд.
- Определение победителя турнира.
- Просмотр статистики участников.

## Выбранный технологический стек

| Компонент | Технология |
|---|---|
| Frontend | React + TypeScript |
| Сборка frontend | Vite |
| Backend | Node.js + Express.js |
| Язык backend | JavaScript |
| Работа с API | REST API (JSON) |
| База данных | SQLite |
| Работа с БД | better-sqlite3 |
| Стилизация | CSS |

Архитектура проекта построена по простой клиент-серверной модели. Frontend отвечает за интерфейс и взаимодействие с пользователем, backend — за обработку данных, формирование турнирных сеток, результаты матчей и статистику.

## Принцип работы

1. Пользователь создаёт турнир и указывает его название и игру.
2. Добавляет участников.
3. Backend формирует турнирную сетку.
4. Пользователь просматривает пары участников и вводит результаты матчей.
5. Система автоматически определяет победителей и перемещает их в следующий раунд.
6. После финального матча определяется победитель турнира.
7. Результаты используются для формирования статистики.

## Особенности MVP

Для первой версии используется формат турнира на выбывание (Single Elimination). Проигравший участник покидает турнир, а победитель проходит в следующий раунд.

Регистрация пользователей, интеграции с игровыми платформами и дополнительные форматы турниров не входят в первоначальную версию проекта.
