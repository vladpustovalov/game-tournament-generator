# План разработки (Roadmap)

## Этап 1. Подготовка проекта

- [ ] Создать структуру репозитория.
- [ ] Настроить React + TypeScript + Vite.
- [ ] Настроить Node.js + Express.
- [ ] Подключить SQLite.
- [ ] Подготовить базовую структуру frontend и backend.

## Этап 2. Backend

- [ ] Создать структуру базы данных.
- [ ] Реализовать создание, получение и удаление турниров.
- [ ] Реализовать добавление и удаление участников.
- [ ] Разработать алгоритм генерации турнирной сетки.
- [ ] Реализовать создание и хранение матчей.
- [ ] Реализовать сохранение результатов матчей.
- [ ] Добавить автоматическое продвижение победителей.
- [ ] Реализовать подсчёт статистики участников.

## Этап 3. Frontend

- [ ] Создать главную страницу со списком турниров.
- [ ] Разработать форму создания турнира.
- [ ] Реализовать интерфейс управления участниками.
- [ ] Создать страницу отдельного турнира.
- [ ] Реализовать отображение турнирной сетки (bracket).
- [ ] Добавить ввод и отображение результатов матчей.
- [ ] Создать блок статистики участников.
- [ ] Настроить адаптивный интерфейс.

## Этап 4. Интеграция и тестирование

- [ ] Подключить frontend к REST API.
- [ ] Проверить создание и удаление турниров.
- [ ] Проверить генерацию турнирных сеток.
- [ ] Проверить обработку результатов матчей.
- [ ] Проверить автоматическое продвижение победителей.
- [ ] Проверить правильность статистики.
- [ ] Исправить найденные ошибки.

## Этап 5. Завершение MVP

- [ ] Проверить работу приложения целиком.
- [ ] Обновить README.md.
- [ ] Добавить инструкции по установке и запуску.
- [ ] Подготовить проект к публикации.

## Возможности для дальнейшего развития

После реализации MVP можно добавить:

- Формат турнира Double Elimination.
- Круговой формат турнира (Round Robin).
- Ручное распределение участников по сетке.
- Регистрацию и авторизацию пользователей.
- Публичные ссылки на турниры.
- Расширенную статистику и историю матчей.
- Экспорт турнирной сетки в изображение или PDF.
- Сохранение и просмотр архивных турниров.
